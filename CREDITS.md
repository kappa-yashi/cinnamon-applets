# Credits

Several of these applets began as forks of existing community applets and were
then heavily rewritten and extended. This file records their origins. All of
them are distributed under the GPL (see `LICENSE`), consistent with their
upstreams.

| Applet | Origin |
|---|---|
| **kappa.yashi Separator** (`separator@kappayashi`) | Original work. |
| **kappa.yashi Launcher** (`launcher@kappayashi`) | Original work. |
| **kappa.yashi Workspace Switcher** (`workspace-switcher@kappayashi`) | Based on a simple community workspace-switcher applet, substantially rewritten. |
| **kappa.yashi Media Controls** (`musiccontrols@kappayashi`) | Based on **Media Controls** by *rbfraphael*. |
| **kappa.yashi Window List** (`grouped-window-list@kappayashi`) | Fork of the built-in **Grouped window list** (`grouped-window-list@cinnamon.org`) by the Linux Mint / Cinnamon team. |
| **kappa.yashi Session Manager** (`sessionManager@kappayashi`) | Fork of **Session Manager** (`sessionManager@scollins`) by *Scott Collins (collinss)*. The system-action backend is kept from the original; the UI was replaced with a fullscreen overlay. |

Thanks to the Linux Mint / Cinnamon project and to the original authors above.
If you are one of them and would like the attribution adjusted, please open an
issue.
